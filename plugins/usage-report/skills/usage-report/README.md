# usage-report skill

Install, update and the monthly routine are in the repo README: https://github.com/Byte-Builders-Co/claude-team-toolkit

Files in this folder:
- `SKILL.md`: entry point (monthly, team and org modes)
- `RUBRIC.md`: judging rubric with anchor examples and fixed labels
- `PERSONAL.md`, `TEAM.md`, `ORG-METHODOLOGY.md`, `DATA-SOURCES.md`: methods
- `team-config.json`: working week, holidays, time zone, plan, language (edited by the team lead)
- `scripts/`: analyze → score → charts → finalize → build_report; `team_summary.py` for the lead
